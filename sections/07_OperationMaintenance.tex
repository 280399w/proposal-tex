\section{運用・保守}

\subsection{運用}
\begin{itemize}
    \item 大会情報の登録・公開
    \item 参加履歴・選手情報の管理
    \item 大会・プレイヤーの検索
    \item 不正利用・荒らしへの対応
    \item サーバ・データベースの管理
\end{itemize}

\subsection{保守}
\begin{itemize}
    \item システムの不具合修正と動作確認
    \item データベースのバックアップと復元確認
    \item 不正アクセス対策、アクセス権限の管理、セキュリティ更新
    \item 大会情報や参加者情報の適切な管理
    \item 大会終了後のデータ保存状況や表示内容の確認
    \item サーバの負荷や通信状況への対応
\end{itemize}

特に、参加者が大会終了後も大会情報を検索できるように、終了した大会は削除せず、
開催予定・開催中・終了済みの状態を区別して管理する。
ただし、大会一覧では開催状況による絞り込みを可能にし、
終了した大会が開催中の大会と混在して分かりにくくならないようにする。

また、プレイヤー検索や配信状況の確認など、配信者や観戦者が利用しやすい機能についても、
利用者の意見をもとに改善する。
配信状況については、配信URLや配信中であることを示す情報を登録できる仕組みを想定し、
外部サービスとの連携が必要な機能は開発状況に応じて追加する。
